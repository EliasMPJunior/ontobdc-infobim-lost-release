## Runtime findings

- The current enum contains ten generated-asset states after `UNDEFINED`, not the three-state `r008/v0.9` subset.
- `GRAPH_READER_SCRIPT_GENERATED` is executable and writes `graph_reader.js`; it is not a stub.
- The enum omits an English description for `VENDOR_SHEET_JS_ASSET_GENERATED`; its YAML description is reported below as a fallback and flagged as such.
