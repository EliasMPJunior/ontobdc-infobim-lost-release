# OntoBDC Documentation

[![License: Apache 2.0](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)

This documentation describes OntoBDC from the user, architecture, specification, and development perspectives.

## Documentation map

### [Getting Started](01-getting-started/)
Installation, first execution, first container, and CLI basics.

### [Concepts](02-concepts/)
Canonical definitions for the concepts used by OntoBDC, including containers, datasets, resources, capabilities, actions, contexts, surfaces, widgets, and semantic runtime concepts.

### [Architecture](03-architecture/)
The internal organization of OntoBDC, its execution model, semantic model, storage, CLI, presentation layer, logging, plugins, and package boundaries.

### [Guides](04-guides/)
Task-oriented documentation showing how to perform real operations with OntoBDC.

### [Reference](05-reference/)
Exact technical reference for commands, parameters, metadata, formats, APIs, and ontologies. Whenever possible, this section must be generated from the implementation source of truth rather than duplicated manually.

### Specifications
Normative contracts that define what an OntoBDC-compatible implementation MUST, SHOULD, and MAY do independently of a specific Python implementation.

### [Architecture Decisions](03-architecture/adr/)
Architecture Decision Records documenting the context, decision, consequences, alternatives, and status of important design choices.

### Development
Repository map, source layout, development environment, tests, contribution rules, and release process.

### Releases
Version-specific release notes and migration information.
