## Main fronts

Release 08 will be developed across three main fronts:

### 1. Refactor

Structural refactoring of the platform and its components.

### 2. IFCX Viewer

Development of the IFCX viewer.

### 3. Events

Development and consolidation of the event architecture and event-related capabilities.
